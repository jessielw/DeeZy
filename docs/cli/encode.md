# deezy encode

`deezy encode <format>` encodes each input to one format. Each format's page lists its options.

| Format | Output | Page |
|---|---|---|
| `dd` | Dolby Digital (AC-3), `.ac3` | [encode dd](encode-dd.md) |
| `ddp` | Dolby Digital Plus (E-AC-3), `.ec3` | [encode ddp](encode-ddp.md) |
| `ddp-bluray` | Dolby Digital Plus 7.1 for Blu-ray, `.ec3` | [encode ddp-bluray](encode-ddp-bluray.md) |
| `ddp-atmos` | Dolby Digital Plus with Dolby Atmos, `.ec3` | [encode ddp-atmos](encode-ddp-atmos.md) |
| `ac4` | Channel-based Dolby AC-4, `.ac4` | [encode ac4](encode-ac4.md) |
| `ac4-ims` | Dolby AC-4 immersive stereo, `.ac4` | [encode ac4-ims](encode-ac4-ims.md) |
| `ac4-atmos` | Dolby AC-4 with Dolby Atmos, `.ac4` | [encode ac4-atmos](encode-ac4-atmos.md) |
| `aac` | AAC-LC, HE-AAC or HE-AAC v2, `.aac` | [encode aac](encode-aac.md) |
| `thd` | Dolby TrueHD, `.thd` | [encode thd](encode-thd.md) |
| `thd-atmos` | Dolby TrueHD with Dolby Atmos, `.thd` | [encode thd-atmos](encode-thd-atmos.md) |
| `preset` | The format the preset names | [encode preset](encode-preset.md) |

## Examples

- Encode one file. The output goes beside it, named from the source:

```bash
deezy encode dd movie.mkv
```

- Encode a folder's files two at a time and keep the temp files:

```bash
deezy encode ddp --max-parallel 2 --keep-temp "media/*.mkv"
```

- Show the names an output template gives, without encoding:

```bash
deezy encode dd --output-template "{title} [{lang}]" --output-preview "media/*.mkv"
```

- Print the commands an encode would run, without running them:

```bash
deezy encode ddp --dry-run movie.mkv
```
