# Dolby Digital (dd)

Dolby Digital (AC-3), written as `.ac3`, for players that don't decode Dolby
Digital Plus. Every option is on [deezy encode dd](../cli/encode-dd.md).

```bash
deezy encode dd movie.mkv
deezy encode dd --channels 2 --bitrate 192 movie.mkv
```

## Layouts

`--channels` picks 1.0 (`1`), 2.0 (`2`) or 5.1 (`6`). With `0` (auto, the
default) DeeZy follows the source: 1 channel gives 1.0, 2 to 5 give 2.0 (a 5.0
source gives 5.0) and 6 or more give 5.1.

- A source with no LFE (5.0, 7.0) is coded as 5.0. `--upmix-50-to-51` codes a
  5.0 source as 5.1 with a silent LFE instead.
- `--disable-lfe` codes 5.1 as 5.0.
- `--stereo-down-mix` picks how a stereo output is mixed from more channels:
  `loro` (the default), `ltrt` or `dpl2`. With `dpl2`, a 2.0 output gets
  FFmpeg's Dolby Pro Logic II mix; any other layout is marked `ltrt`, because
  DEE's Dolby Digital encoder takes no Pro Logic II downmix mode.
- `--lo-ro-center`, `--lo-ro-surround`, `--lt-rt-center` and `--lt-rt-surround`
  set the levels a player uses when it downmixes the stream (-3 dB by default).

`--bitrate` picks a rate; one DEE doesn't take becomes the closest one it does,

## Loudness

By default DEE measures the loudness (ITU-R BS.1770-4) and writes the measured
dialnorm into the stream. The audio isn't changed.

- `--custom-dialnorm -27` writes that dialnorm without measuring.
- `--loudness-target -24` measures and corrects the audio to that loudness
  (-31 to -8 LKFS). `--peak-limit` (-12 to -0.1 dBTP, at least 6 dB above the
  target) sets the true-peak limit, -2 by default. Neither works with
  `--custom-dialnorm`.
- `--loudness-preset` (`atsc_a85`, `ebu_r128`, `freetv_op59` or `arib_b32`)
  measures to that regulation instead of the manual settings, so
  `--no-dialogue-intelligence` and `--speech-threshold` don't apply and it can't
  be combined with `--loudness-target`. `--custom-dialnorm` still wins. A preset
  changes the measured dialnorm: on one Atmos clip `manual` gave -18 and
  `ebu_r128` gave -13.

```bash
deezy encode dd --loudness-target -24 movie.mkv
deezy encode dd --loudness-preset ebu_r128 movie.mkv
```

## Processing

- `--drc-line-mode` and `--drc-rf-mode` pick the dynamic range compression
  profiles (`film_light` by default; `none` turns it off). See [DRC](../drc.md).
- `--surround-3db` lowers the surround channels by 3 dB. It is off by default,
  as in DEE (DeeZy 1.x turned it on).
- `--no-surround-90-deg-phase-shift` turns off the surround phase shift.
- `--no-low-pass-filter` turns off the LFE's low-pass filter.

## From an Atmos source

A TrueHD Atmos track is encoded from FFmpeg's 7.1 decode of it. DEE renders an
Atmos master (DAMF or ADM BWF) to the layout itself, 5.1 at most.
