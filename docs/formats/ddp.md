# Dolby Digital Plus (ddp)

Dolby Digital Plus (E-AC-3), written as `.ec3`. Every option is on
[deezy encode ddp](../cli/encode-ddp.md).

```bash
deezy encode ddp movie.mkv
deezy encode ddp --channels 8 --bitrate 1024 movie.mkv
```

## Layouts

`--channels` picks 1.0 (`1`), 2.0 (`2`), 5.1 (`6`) or 7.1 (`8`). Auto (`0`, the
default) follows the source as for [Dolby Digital](dd.md#layouts), and gives an
8-channel source 7.1 when DeeZy has [dee_shim](../dee-shim.md), else 5.1 with a
notice.

- 7.1 and 7.0 need dee_shim: DEE alone codes DD+ 7.1 only for Blu-ray (see
  [ddp-bluray](ddp-bluray.md)). Without dee_shim, `--channels 8` is refused.
- A source with no LFE is coded as 5.0, or a 7.0 source as 7.0 through
  dee_shim (5.0 without it). `--upmix-50-to-51` codes a 5.0 source as 5.1 with a
  silent LFE.
- `--disable-lfe` codes 5.1 as 5.0 and 7.1 as 7.0 (through dee_shim).
- `--stereo-down-mix` (`loro` by default, `ltrt` or `dpl2`) picks how DEE mixes
  a 2.0 output, and the downmix it marks in the stream for players. DD+ takes
  `dpl2` for every layout. The downmix levels work as for DD.

## Blu-ray secondary audio

`--bluray-secondary` makes Blu-ray secondary audio: 2.0 or 5.1, at the rates
listed on [ddp-bluray](ddp-bluray.md#data-rates) (192 kbps by default). A rate
it doesn't take becomes the closest one it does, with a warning.
`--loudness-target` works with it; `--user-data` doesn't. DEE keeps the LFE of
secondary audio, so `--disable-lfe` gives it a silent one.

```bash
deezy encode ddp --bluray-secondary --channels 2 movie.mkv
```

## Loudness

As for [Dolby Digital](dd.md#loudness): DEE measures the loudness and writes the measured dialnorm, and `--custom-dialnorm`, `--loudness-target` and `--loudness-preset` work the same way.

## Other options

- `--user-data N` writes a user data ID into the stream (-1, the default, writes
  none).
- DRC, `--surround-3db` (off by default), the phase shift and the LFE low-pass
  filter work as for [Dolby Digital](dd.md#processing).

## From an Atmos source

As for [Dolby Digital](dd.md#from-an-atmos-source): a TrueHD Atmos track is
encoded from FFmpeg's 7.1 decode, and DEE renders an Atmos master to 5.1 at
most. Use [ddp-atmos](ddp-atmos.md) to keep the objects.
