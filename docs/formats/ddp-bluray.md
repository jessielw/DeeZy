# Dolby Digital Plus for Blu-ray (ddp-bluray)

Dolby Digital Plus 7.1 as Blu-ray carries it: an AC-3 core with an E-AC-3
extension, written as `.ec3`. Every option is on
[deezy encode ddp-bluray](../cli/encode-ddp-bluray.md). For Blu-ray secondary
audio use [`ddp --bluray-secondary`](ddp.md#blu-ray-secondary-audio).

```bash
deezy encode ddp-bluray movie.mkv
deezy encode ddp-bluray --bitrate 1664 movie.mkv
```

## Layouts

The output is 7.1. A 7.0 source is coded as 7.0 through
[dee_shim](../dee-shim.md), else as 7.1 with a silent LFE; `--disable-lfe` does
the same. A source of fewer channels is refused (DeeZy doesn't up-mix), and so is
an Atmos master: DEE's Blu-ray mode doesn't take one. Use [ddp](ddp.md) or
[ddp-atmos](ddp-atmos.md) for those.

## Loudness

DEE measures the loudness and writes the measured dialnorm. `--custom-dialnorm`
and `--loudness-preset` work as for [Dolby Digital](dd.md#loudness);
`--loudness-target` isn't available for Blu-ray.

## Processing

DRC, `--surround-3db` (off by default), the phase shift, the LFE low-pass filter
and the downmix options work as for [Dolby Digital](dd.md#processing).
