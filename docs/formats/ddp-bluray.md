# DDP BluRay

Specialized DDP encoding optimized for BluRay disc mastering.

Examples

```bash
deezy encode ddp-bluray input.mkv
deezy encode ddp-bluray --bitrate 1536 input.mkv
```

## Split DEE encoders

Not available with the split DEE encoders (the Blu-ray 7.1 mode needs the single `dee` executable). DeeZy stops with a message. See [Installation](../installation.md).
