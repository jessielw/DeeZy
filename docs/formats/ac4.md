# Dolby AC-4 (ac4)

Channel-based Dolby AC-4, written as `.ac4`. Every option is on
[deezy encode ac4](../cli/encode-ac4.md).

In DeeZy 1.x `ac4` made immersive stereo, which is now [ac4-ims](ac4-ims.md).
DeeZy logs a notice each time `ac4` runs.

```bash
deezy encode ac4 movie.mkv
deezy encode ac4 --channels 2 --bitrate 128 movie.mkv
```

## Layouts

`--channels` picks 2.0 (`2`) or 5.1 (`6`). Auto (`0`, the default) gives a
source of 5 channels or more 5.1 (a 5.0 source gets a silent LFE; DEE downmixes
7.1) and a smaller one 2.0. A mono source becomes 2.0 at -3 dB per channel, so
it measures as loud as the mono. `--disable-lfe` gives 5.1 a silent LFE.

## Loudness

DEE measures the loudness and writes it into the stream. `--loudness-target`
(-31 to -10 LKFS for AC-4) and `--peak-limit` correct it, and
`--loudness-preset` measures to a regulation, as for
[Dolby Digital](dd.md#loudness).

## DRC

AC-4 has a DRC profile per kind of device: `--flat-panel-drc`,
`--home-theatre-drc`, `--portable-headphones-drc` and
`--portable-speakers-drc`. They take every profile but `none`.

## Sync

DeeZy compensates the delay DEE's manifest reports. It hasn't been checked
against an AC-4 decoder.
