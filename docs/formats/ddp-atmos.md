# Dolby Digital Plus with Dolby Atmos (ddp-atmos)

Dolby Digital Plus with Dolby Atmos (JOC), written as `.ec3`. Every option is on
[deezy encode ddp-atmos](../cli/encode-ddp-atmos.md). DeeZy 1.x called this
format `atmos`.

```bash
deezy encode ddp-atmos movie.mkv
deezy encode ddp-atmos --atmos-mode bluray master.atmos
```

## Sources

The source is a TrueHD Atmos track (truehdd decodes it to a DAMF master first, so DeeZy needs truehdd), a DAMF master (the `.atmos` file, beside its `.atmos.metadata` and `.atmos.audio`) or an ADM BWF master (`.wav`). A channel-based source is refused.

## Modes

| `--atmos-mode` | Backbone | Default rate | Needs dee_shim |
|---|---|---|---|
| `streaming` (default) | 5.1 | 448 kbps | no |
| `standard` | 7.1 as E-AC-3 | 1152 kbps | yes |
| `bluray` | 7.1 with an AC-3 core | 1280 kbps | yes |

Without [dee_shim](../dee-shim.md), DEE's own Blu-ray mode makes a 5.1.2
backbone, so DeeZy refuses `standard` and `bluray`.

DEE fails some `standard` streams below about 432 kbps, depending on the
content, so DeeZy takes 448 kbps and up.

## Through dee_shim

When DeeZy finds dee_shim, every ddp-atmos encode runs through it:

- dee_shim codes the master's object metadata as it is
  (`--oamd-as-is on`). `--no-oamd-as-is` lets DEE smooth it, as plain DEE does,
  and gives plain DEE's output.
- `--no-surround-90-deg-phase-shift` turns off the backbone's surround phase
  shift. It needs dee_shim.

## Loudness

From a master DEE can only measure the loudness (the default) or write a set
dialnorm (`--custom-dialnorm`); it can't correct it. `--loudness-preset` works as
for [Dolby Digital](dd.md#loudness).

## Warp mode

A TrueHD Atmos stream that carries no warp mode reaches DEE with none, which DEE renders as `warping`, its own default. `--thd-warp-mode` gives such a stream one (`normal`, `warping`, `prologiciix` or `loro`). A stream that has a warp mode keeps it. DeeZy 1.x gave every such stream `normal`.

## MediaInfo

MediaInfo can show a 7.1 (`standard` or `bluray`) stream from DEE as plain
"Dolby Digital Plus", without Atmos. DEE splits the Atmos metadata across the
stream in a way MediaInfo misreads; plain DEE's output shows the same, and the
stream is fine.
